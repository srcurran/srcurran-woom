## Writing with Markdown

Use **bold**, *italic*, ~~strikethrough~~, and [links](https://example.com).

- Keep a Markdown file in its own folder.
- Put images and videos alongside it or in a nested `media` folder.

> A little space for a thought worth remembering.

```js
const greeting = 'Hello, world';
console.log(greeting);
```

| Format | Use |
| --- | --- |
| Markdown | The article |
| Images and videos | Files beside the article |

See `BLOG.md` at the project root for media examples and publishing instructions.
